# IT Infrastructure Labs

A collection of hands-on IT infrastructure projects demonstrating practical skills in hardware diagnostics, data protection, cybersecurity, networking, Linux administration, and virtualization.

Each project documents real-world scenarios, technical implementation, troubleshooting, and verified results using physical hardware and virtual lab environments.

## Projects

| Project | Description | Status |
| :--- | :--- | :--- |
| [01 — Storage Lifecycle Management](01-storage-lifecycle-management/README.md) | HDD diagnostics, forensic imaging, data recovery, backup and restoration, encryption, and secure drive retirement. | Completed |

## Technical Skills Demonstrated

- Hardware diagnostics and storage troubleshooting
- Forensic disk imaging and data recovery
- Backup integrity verification and restoration testing
- Windows BitLocker and TPM-backed device encryption
- Linux command-line administration
- Cryptographic integrity verification using SHA-256
- Secure data sanitization and hardware retirement
- Technical documentation and evidence-based troubleshooting

## Lab Environment

| Component | Environment |
| :--- | :--- |
| Operating Systems | Windows 11 Pro, Windows 11 Home, Ubuntu Linux, Ubuntu Server |
| Virtualization | Oracle VirtualBox |

| Backup and Verification | FreeFileSync, PowerShell, SHA-256 |
| Security | BitLocker, BitLocker To Go, TPM 2.0 |

## Project Documentation

Each project includes:

- Project objectives and scope

- Verification and technical results
